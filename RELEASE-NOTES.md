# Questie-X v1.6.4 — Compatibility Fixes

- Routes modulo arithmetic through the Lua 5.0 compatible `math.mod` shim so the addon parses on the Vanilla 1.12 client and newer.
- Fixes option-tab table initialization for Lua 5.0 and 5.1 compatibility.
- Packages Questie-X with the WotLK and Ascension data modules.

The package changelog notes that additional performance work remains on separate branches and is not included in this build. This release is marked as a prerelease; in-game validation is not confirmed here.
